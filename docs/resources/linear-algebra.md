# Linear algebra

Linear algebra is already held deeply — the Kostrikin/Gelfand tradition, see
[profile](../profile.md). These are relevant only as sources of *problems*, not as courses, and
nothing here should be adapted into a route through material already owned.

### halmos-linear-algebra-problem-book — Halmos, *Linear Algebra Problem Book* { #halmos-linear-algebra-problem-book }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* The closest match to a discover-the-theory-yourself approach: question → think → hint →
solution. Inquiry-based rather than expository, which makes it the one book in this subject worth
acquiring — it supplies problems, which is the only thing missing.

### treil-linear-algebra-done-wrong — Treil, *Linear Algebra Done Wrong* { #treil-linear-algebra-done-wrong }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** author-hosted; free edition believed to exist
**Status:** unvetted · **Adapted:** none

*(unvetted)* Useful for connections outward to geometry, analysis and probability. Use when a
systematic explanation is wanted; [Halmos](#halmos-linear-algebra-problem-book) first.
