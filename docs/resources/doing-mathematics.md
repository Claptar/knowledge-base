# Doing mathematics

Process and heuristics rather than content — how mathematics is actually made, as opposed to how it
is presented once finished. This subject exists because the complaint that opened this knowledge
base was about presentation: definitions that arrive without motivation, proofs chosen for
convenience.

### lakatos-proofs-refutations — Lakatos, *Proofs and Refutations* { #lakatos-proofs-refutations }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Not a textbook; a dialogue on how mathematics actually develops: conjecture, attempted
proof, counterexample, broken proof, revised definition, deeper structure. Aimed squarely at the
complaint that polished textbook proofs hide the process that produced them. Weakness: gives no
machinery, so it pairs with a technical text rather than replacing one.
