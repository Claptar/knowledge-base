# Stochastic processes

Resnick and van Kampen answer different questions — *how do these objects behave mathematically?*
versus *where do these equations come from?* — and are complements, not alternatives. Both are held
locally; both are all-rights-reserved, so neither may be adapted into the published site.

### van-kampen-sppc — van Kampen, *Stochastic Processes in Physics and Chemistry* { #van-kampen-sppc }

**Kind:** book · **Access:** local · `sources/van-kampen-sppc/book.pdf`
**Licence:** all rights reserved — any adaptation goes to `adapted-private/`
**Status:** unvetted · **Adapted:** none

*(unvetted)* The mechanism map, not the probability map: microscopic randomness → transition rates →
master equations → macroscopic behaviour and fluctuations, with the jump process → master equation →
Fokker–Planck ↔ Langevin chain made explicit. Directly relevant to the
[CME literature](cme-transcription.md) and stochastic gene expression, and it is the book that
treats the derivation of a stochastic description as the subject rather than the preamble.

Likely the most valuable single book here given current direction — and the one whose adaptation
would be most useful and least publishable.

### resnick-adventures — Resnick, *Adventures in Stochastic Processes* { #resnick-adventures }

**Kind:** book · **Access:** local · `sources/resnick-adventures/book.pdf`
**Licence:** all rights reserved — any adaptation goes to `adapted-private/`
**Status:** unvetted · **Adapted:** none

*(unvetted)* Organised around concrete processes rather than abstract machinery: Markov chains,
renewal theory, point processes, continuous-time Markov chains, Brownian motion, random walks.
Motivation before abstraction, and explicit about which arguments are rigorous and which are
plausibility arguments — that explicitness is unusual and is the reason to prefer it. This is the
probability-theory map.

### ross-probability-models — Ross, *Introduction to Probability Models* { #ross-probability-models }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Applied probability: Markov chains, queueing, reliability. Weaker than
[van Kampen](#van-kampen-sppc) on *why* a stochastic description follows from the mechanism; use for
worked applications only. Lowest acquisition priority in this subject.
