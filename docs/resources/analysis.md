# Analysis

## Real analysis

Suggested route: Abbott → Pugh, with Hairer & Wanner in parallel for historical motivation.

### abbott-understanding-analysis — Abbott, *Understanding Analysis* { #abbott-understanding-analysis }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Recommended as the first choice: questions posed before the formal result, heavy use of
counterexamples, motivates *why* completeness, compactness, uniform convergence and continuity are
formulated as they are. Likely too introductory in places given my background — treat as a
motivation source, not a course.

### pugh-real-mathematical-analysis — Pugh, *Real Mathematical Analysis* { #pugh-real-mathematical-analysis }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* The step after [Abbott](#abbott-understanding-analysis): geometric intuition, unusual
examples, reaches multivariable analysis, function spaces and measure-adjacent topics.

### hairer-wanner-analysis-by-its-history — Hairer & Wanner, *Analysis by Its History* { #hairer-wanner-analysis-by-its-history }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Read alongside the above for how analysis actually arose, rather than the modern
logical structure presented as if it were always there.

## Complex analysis

Pairing: Needham for geometry and intuition, Stein–Shakarchi for rigour and connections.

### needham-visual-complex-analysis — Needham, *Visual Complex Analysis* { #needham-visual-complex-analysis }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Geometry first; complex functions as transformations; Cauchy's theorem, Möbius
transformations, winding numbers and harmonic functions given geometric meaning. The flagship
example of a book asking what the mathematics *means*.

### stein-shakarchi-complex-analysis — Stein & Shakarchi, *Complex Analysis* { #stein-shakarchi-complex-analysis }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* The rigour-and-connections counterpart to [Needham](#needham-visual-complex-analysis):
Fourier analysis, zeta functions, elliptic functions, number theory.
