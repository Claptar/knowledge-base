# Statistics

## The main text and its companion

The division of labour worth holding onto: DeGroot is machinery, Cox is meaning.

### degroot-schervish — DeGroot & Schervish, *Probability and Statistics* { #degroot-schervish }

**Kind:** book · **Access:** local · `sources/degroot-schervish/book.pdf`
**Licence:** all rights reserved — any adaptation stays unpublished
**Status:** reading — the current main text · **Adapted:** none

Formal definitions, derivations, sampling distributions, estimation, likelihood, Bayesian methods,
testing, linear models, exercises. Machinery, not meaning — it tells you how to analyse
$X_1,\dots,X_n \overset{iid}{\sim} N(\mu,\sigma^2)$ and not why you were entitled to write that
model down. For the second question see [Cox](#cox-principles-of-statistical-inference) and
[Freedman](#freedman-statistical-models).

### cox-principles-of-statistical-inference — Cox, *Principles of Statistical Inference* { #cox-principles-of-statistical-inference }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Recommended as the single best companion to [DeGroot](#degroot-schervish): what
statistical evidence *is*, why likelihood, what confidence procedures actually mean, why tests have
the structure they do, how Fisherian/frequentist/Bayesian reasoning differ.

## The wider map

### efron-hastie-casi — Efron & Hastie, *Computer Age Statistical Inference* { #efron-hastie-casi }

**Kind:** book · **Access:** fetchable · <https://hastie.su.domains/CASI/>
**Licence:** all rights reserved; free PDF hosted with the publisher's permission
**Status:** unvetted · **Adapted:** none

*(unvetted)* The intellectual map of modern statistics: classical inference through empirical Bayes,
James–Stein, bootstrap, cross-validation, regularisation, multiple testing, forests, boosting. Best
dipped into for "where does this classical idea lead?", not read linearly.

Verified 2026-09-13: the authors' page states the PDF is available with the publisher's permission,
though it is reached through the order page rather than a direct file link.

### freedman-statistical-models — Freedman, *Statistical Models: Theory and Practice* { #freedman-statistical-models }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* For modelling judgement and criticism: why IID, why Gaussian, why linear, why should
this coefficient be causal, where did the sample come from. The counterweight to DeGroot's "given
this model…".

### gelman-hill-vehtari-ros — Gelman, Hill & Vehtari, *Regression and Other Stories* { #gelman-hill-vehtari-ros }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved; free edition believed to exist
**Status:** unvetted · **Adapted:** none

*(unvetted)* Regression as a modelling activity rather than a formula: assumptions, diagnostics,
predictive simulation, residual analysis, model checking, cross-validation, interpretation.
