# Modelling

Modelling craft, optimisation as a modelling activity, and the credibility half — validation and
uncertainty. See [topics/mathematical-modelling](../topics/mathematical-modelling.md) for the
methodology these support.

## Modelling craft

### meerschaert-mathematical-modeling — Meerschaert, *Mathematical Modeling* { #meerschaert-mathematical-modeling }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Recommended as the best single starting book if the goal is to learn modelling
explicitly: optimisation, dynamical systems and stochastic models treated as one activity, with the
full loop from problem formulation through sensitivity and robustness.

### bender-intro-mathematical-modeling — Bender, *An Introduction to Mathematical Modeling* { #bender-intro-mathematical-modeling }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Real problems, model construction, and sustained criticism of assumptions — deciding
whether a model is *useful* rather than whether it is solvable.

### gershenfeld-nature-of-mathematical-modeling — Gershenfeld, *The Nature of Mathematical Modeling* { #gershenfeld-nature-of-mathematical-modeling }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* A broad map: ODEs, PDEs, variational methods, stochastic processes, numerics, finite
elements, inference, density estimation, state estimation, HMMs, time series. Value is in showing
these belong to one enterprise; too thin to be a sole technical text on any of them.

### mahajan-street-fighting-mathematics — Mahajan, *Street-Fighting Mathematics* { #mahajan-street-fighting-mathematics }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** believed CC-licensed via MIT Press open access
**Status:** unvetted · **Adapted:** none

*(unvetted)* Dimensional analysis, limiting cases, lumping, scaling, order-of-magnitude reasoning,
successive approximation, analogy. Short and practical. The habit it trains — ask what must be true
on dimensional or asymptotic grounds before computing — is one of the most transferable in applied
maths. Barenblatt on scaling is the advanced continuation.

> **Unverified.** MIT Press released several titles under Creative Commons and this is believed to
> be one. If confirmed, it becomes `fetchable` *and* adaptations become publishable — worth
> resolving, since it would be the only adaptable book in the catalogue.

## Optimisation

### hp-williams-model-building — H. P. Williams, *Model Building in Mathematical Programming* { #hp-williams-model-building }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Covers the part most optimisation books omit: turning a real problem into an
optimisation problem — choosing decision variables, constructing constraints and objectives,
linearisation, integer variables, and the computational consequences of formulation choices.

### boyd-vandenberghe-convex-optimization — Boyd & Vandenberghe, *Convex Optimization* { #boyd-vandenberghe-convex-optimization }

**Kind:** book · **Access:** fetchable · <https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf>
**Licence:** copyright Cambridge University Press; hosted free by the authors with permission
**Status:** worked — via EE364A · **Adapted:** none

Already worked through. The theory side, to be used *after* the formulation question rather than
instead of it — which is exactly the gap [H. P. Williams](#hp-williams-model-building) is for.

Verified 2026-09-13: the authors' page states CUP has agreed to keep the book on the web.

## Validation and uncertainty

### oberkampf-roy-verification-validation — Oberkampf & Roy, *Verification and Validation in Scientific Computing* { #oberkampf-roy-verification-validation }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Code verification, solution verification, model validation, prediction, comparison with
experimental data. The reference for the verification/validation distinction — solving the model
right versus choosing the right model.

### smith-uncertainty-quantification — Smith, *Uncertainty Quantification* { #smith-uncertainty-quantification }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Parameter uncertainty, sensitivity analysis, calibration, identifiability, uncertainty
propagation, model discrepancy, surrogate and reduced-order models. Flagged as a later read — worth
most after several models have actually been built.

### calvetti-somersalo-bayesian-scientific-computing — Calvetti & Somersalo, *Bayesian Scientific Computing* { #calvetti-somersalo-bayesian-scientific-computing }

**Kind:** book · **Access:** unreadable — no copy held
**Licence:** all rights reserved
**Status:** unvetted · **Adapted:** none

*(unvetted)* Inverse problems combined with scientific computing and Bayesian inference:
identifiability, ill-posedness, regularisation, priors, non-uniqueness under noisy observation.
